# ACS
## When I first wanted to make my own AI, I ofcourse didnt really know how AIs worked but I still wanted to make my own one. The online tutorials and so on were all too complex for my brain, so I decided on making my own system. I dubbed it ACS (Actions-Conditions
System). 

Here is How it works: We make a matrix of values (all starting at say zero, so an zero matrix). We make conditions (the things the AI takes into consideration in its decision-making, booleon values) as the rows and the actions (the things the AI can choose to do) as the columns.
